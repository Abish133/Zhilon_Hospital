🔧 STEP 2: Deploy Backend Service
═══════════════════════════════════════════════════════════════════════════════

1. Click "+ New" button
2. Select "GitHub Repo"
3. Choose: Abish133/Zhilon_Hospital
4. Railway will create a new service

5. Click on the new service
6. Go to "Settings" tab
7. Set these:
   - Root Directory: backend
   - Start Command: npm run migrate && npm start

8. Go to "Variables" tab
9. Click "Add Variable" and add these ONE BY ONE:

   NODE_ENV=production
   PORT=5000
   DB_HOST=${{MySQL.MYSQLHOST}}
   DB_PORT=${{MySQL.MYSQLPORT}}
   DB_NAME=${{MySQL.MYSQLDATABASE}}
   DB_USER=${{MySQL.MYSQLUSER}}
   DB_PASS=${{MySQL.MYSQLPASSWORD}}
   DB_DIALECT=mysql
   DB_POOL_MAX=20
   DB_POOL_MIN=5
   DB_POOL_ACQUIRE=60000
   DB_POOL_IDLE=10000
   JWT_SECRET=zhilon_hospital_secret_key_2024_production
   JWT_EXPIRES_IN=8h
   CORS_ORIGIN=*
   UPLOAD_DIR=uploads
   MAX_FILE_SIZE=10485760
   RATE_LIMIT_WINDOW_MS=900000
   RATE_LIMIT_MAX=500

10. Go to "Settings" → "Networking"
11. Click "Generate Domain"
12. COPY THE BACKEND URL (you'll need it for frontend)

🎨 STEP 3: Deploy Frontend Service
═══════════════════════════════════════════════════════════════════════════════

1. Click "+ New" button again
2. Select "GitHub Repo"
3. Choose: Abish133/Zhilon_Hospital (same repo)
4. Railway will create another service

5. Click on this new service
6. Go to "Settings" tab
7. Set these:
   - Root Directory: frontend
   - Build Command: npm install && npm run build
   - Start Command: npx serve -s dist -l $PORT

8. Go to "Variables" tab
9. Add this variable:

   VITE_API_BASE_URL=https://YOUR_BACKEND_URL/api

   ⚠️ IMPORTANT: Replace YOUR_BACKEND_URL with the actual backend URL from Step 2

10. Go to "Settings" → "Networking"
11. Click "Generate Domain"
12. COPY THE FRONTEND URL
